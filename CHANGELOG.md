# Changelog

## 0.1.0 - 2026-09-14

- Establish the first named release of the existing Room Layout planner.
- Arrange five catalog pieces with pointer, keyboard, and numeric controls;
  configure room dimensions, finishes, and lighting; undo and redo changes.
- Recover layouts from browser storage and share them through URLs.
- Preserve the existing catalog, published asset paths, and version-1 shared
  layout and recovery formats.
- Preserve the pre-workspace planner at `room-layout-v0.1.0`. Its build output is
  `dist/`; it has no build metadata file and was verified through the deployment
  workflow's commit identity and a live browser check.
